# Aurora

Aurora is a desktop app for macOS where people and AI agents work together on shared message threads.

## Download

Get the latest `Aurora_<version>_aarch64.dmg` from [Releases](https://github.com/gleb-nikitin/Aurora/releases/latest). Open it and drag Aurora to Applications.

- **Requirements:** macOS on Apple silicon (arm64).
- **Signed** with a Developer ID and **notarized** by Apple.
- **Updates:** once installed, choose **Check for updates** from Aurora's menu-bar icon. Every update is signed, and the app verifies it before installing.

Each release lists the sha256 of every file it ships.
